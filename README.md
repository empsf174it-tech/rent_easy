# Rent Easy - Car Rental Template

Rent Easy is a premium, multi-page HTML template designed specifically for Car Rental services in the Automotive industry. It follows an editorial and modern-clean aesthetic, focusing on luxury, ample white space, and sharp typography.

## Pages (8 Pages)
1. `index.html` - Primary homepage
2. `about.html` - About Us page
3. `fleet.html` - Vehicle catalog with client-side filters
4. `booking.html` - Booking flow with vehicle and date selection
5. `contact.html` - Contact form with map placeholder
6. `login.html` - Tabbed Login and Register forms (Merged for page budget)
7. `dashboard.html` - User account and booking management
8. `404.html` - Error page

## Features
- **Design System**: Monochromatic base (Slate) with muted gold accents.
- **Typography**: Playfair Display (Headings) and Outfit (Body).
- **Responsive**: Full desktop nav (>1024px) and mobile slide-drawer (<=1024px).
- **Dark Mode**: Toggleable and persistent via `localStorage`.
- **RTL Support**: Toggleable layout direction with `dir="rtl"` and `rtl.css`.
- **Validation**: Full client-side form validation built-in.

## Structure
- `assets/css/style.css` - All styling variables and layout code.
- `assets/css/rtl.css` - Overrides for Right-To-Left layout.
- `assets/js/main.js` - Global interactions (nav, theme, RTL, validation).
- `assets/js/booking.js` - Fleet filtering and booking logic.

## Setup
No build steps required. Simply open any `.html` file in your browser to view the template.
